我是烁。白天写业务前端，主要跟 TypeScript 和 CSS 打交道；晚上写自己的小项目，通常做不完。

从 2020 年开始写代码，做过三年后台管理系统——表格套表单、表单套弹窗那种。也正因为如此，我对"能用"的标准比一般人苛刻一点。现在更偏基础设施：组件库、构建流程、把一个跑了五年的前端仓库从 jQuery 里捞出来。

## 我在做什么

手上的三个东西：这个博客（第三版了，前两版在 Hexo 和 Next.js 上，每次重写的理由都一样——旧的那套让我改不动）；一个自用工具箱，时间戳、JSON、正则、对比度这些都在里面，日活三十人，二十个是我在不同设备上的自己；还有一个纯本地记账工具，数据只存在浏览器的 IndexedDB 里，没写完，写完会在这里说。

## 这个站写什么

**笔记**写技术，只写具体的东西：某个框架升级踩了什么坑、一段 CSS 为什么在 Safari 上不生效、某个 API 的设计取舍。尽量给可复现的代码和数字，因为我自己最烦"配置一下就好了"这种答案。

**随笔**写想法，多跟设计、审美、工作方式有关。没什么实用价值，但写得最认真。

**工具**写我在用的东西，只说"我拿它干什么、为什么半年后它还在我任务栏上"。

不做新闻搬运，不写"10 个你必须知道的技巧"，不为更新而更新。

## 怎么联系

### 平台

- **GitHub**：页脚的图标，代码和 issue 都在那里。
- **RSS**：[/rss.xml](/rss.xml)，我更希望你订阅，而不是靠平台推荐。

### 联系

站内没有评论区，也只开了 GitHub 一个口子——公开渠道留得越多，找上门来的推广越多。有话去 GitHub 开个 issue，写得具体我都会回，比如"你文章里这段代码在 Node 18 上报错"。回得慢，但会看。
