每隔一段时间就会有一批"赛博朋克风"网页出现在设计平台上。它们的共同特征是：紫蓝渐变背景、青色发光标题、网格地平线、扫描线叠加层、偶尔来一段文字抖动。单看配色卡，和《银翼杀手 2049》的海报确实接近。但把它们放在一起看，几乎每一张都显得脏、拥挤、廉价。

我觉得问题不在"用了什么颜色"，而在三件事：暗部不够暗、发光到处乱放、动效没有节制。

## 一、暗部不够暗，霓虹就变成脏

最常见的错误背景色是 `#1a1a2e` 或者 `#12121f` 这类"看起来很暗"的深蓝紫。它们的问题是在显示器上并不黑——亮度值大约在 8% 到 12% 之间，还带着明显的蓝色偏移。

在这个底色上叠一个 `#00ffff` 的青色文字，会发生什么？青色的边缘和背景混在一起，因为两者之间的亮度差不够大。文字看起来不是"发光的字"，而是"一圈糊掉的蓝绿色"。这就是脏的来源。

真正的暗部应该压到什么程度？我的经验是背景亮度不超过 5%，而且要尽量接近中性，让颜色信息全部留给发光体。`#0a0a0f`、`#08080c` 这类接近纯黑的底色，才能让霓虹色"跳"出来。对比一下：

```css
/* 脏：背景自己带色，青色发光被吃掉 */
.hero-bad {
  background: #1a1a2e;
  color: #7fffff;
  text-shadow: 0 0 8px #00ffff;
}

/* 净：背景让位，亮度和饱和度都交给焦点 */
.hero-good {
  background: #08080c;
  color: #eafffb;
  text-shadow:
    0 0 1px #38f5d0,
    0 0 12px rgb(56 245 208 / 0.55),
    0 0 40px rgb(56 245 208 / 0.25);
}
```

注意第二段代码里，文字的本体颜色是接近白的 `#eafffb`，不是青色。发光是加在它外面的三层光晕，而不是把字本身染成荧光色。这一点极少有人做对：**发光的东西本体必须够亮，光晕才是"溢出"的错觉。**把字染成青绿再去加青绿的光，等于用同一个颜色画物体和影子，体积感立刻消失。

## 二、发光要稀缺，才叫发光

第二个问题：整页都在发光。

标题发光、按钮发光、卡片边框发光、滚动条也发光。当所有元素都在喊，就没有元素在说话。这是视觉上的通货膨胀——每多一个发光源，其他发光源的价值就贬值一次。

我会把一屏的发光源限制在一个到两个，而且必须有一个是明确的视觉落点：主标题，或者核心按钮。其他部分全部退回到"不发光的暗部"里，只用 1px 的低透明度描边暗示存在。

```css
/* 不发光但依然有边界：1px 描边 + 极低透明度底色 */
.panel {
  background: rgb(255 255 255 / 0.03);
  border: 1px solid rgb(56 245 208 / 0.18);
  border-radius: 4px;
}
```

一层 3% 的白 + 一条 18% 的青边，在纯黑底上已经有足够的存在感了。它不发光，但它被看见——这恰恰是发光标题需要的对比。

顺便说 `filter: blur()`。很多效果为了"氛围"给整个容器加 `filter: blur(40px)`。它在移动端会让整层参与重绘，滚动时掉帧非常明显。光晕优先用 `box-shadow` 或 `text-shadow`，合成器能优化；大面积模糊只留给静态的、不随滚动重绘的元素。

## 三、动效的节制，是最难的部分

赛博朋克的视觉语言来自"故障"和"信号噪声"，很多人理解成"页面应该在动"：扫描线常驻、随机 glitch、粒子背景、光标拖尾一起上。

我见过一个页面，四秒里主视觉动了七次。你没法读任何字。

我的建议是把动效拆成两类：

- **状态反馈**：悬停、聚焦、切换。这类必须有，时长 120–200ms，`ease-out`，只动 `transform` 和 `opacity`。
- **氛围暗示**：扫描线、噪声、缓慢漂移。这类最多留一种，频率低到几乎注意不到——我一般用 8 秒以上的对称循环，或者干脆做成静态纹理。

有一点常被忽略：动效的"贵"不体现在代码量，而体现在对比。一个静止的暗页面里，一次 150ms 的轻微上移，比一个持续抖动的标题有力量得多。

```css
@media (prefers-reduced-motion: reduce) {
  .scanline,
  .flicker {
    animation: none;
  }
}
```

这行 `prefers-reduced-motion` 不是可选项。前庭功能障碍的人对持续位移会生理性不适，而"故障感"恰好是持续位移的重灾区。

## 四、其实这套美学的内核不是颜色

如果只允许我说一句话总结赛博朋克，我会说：它是**极高密度的信息**和**极低容忍度的秩序**同时存在。

《攻壳机动队》的城市镜头里，招牌、线缆、广告牌堆到没有空隙，但每一条都在自己的层级上：远景是低饱和的压缩块，近景才出现高饱和的霓虹。《银翼杀手 2049》更极端，Deakins 用大雾把远处全部压成一个色相，只让一个人形的轮廓亮着。

赛博朋克的视觉张力来自"乱"和"准"的对抗：信息是乱的、密集的，但光线的秩序是精确的、有主次的。你在网页上做不砸的方法，恰恰是先把秩序做好——把暗部压死、把焦点收窄、把动效砍掉一半——然后再往里塞信息密度。

配色是这套东西的结果，不是配方。

## 一个可操作的自检清单

我做完这类页面会问自己五个问题：

1. 把页面截图转成灰度，还能看出主次吗？如果全屏灰扑扑一片，说明对比是靠色相撑的。
2. 一屏之内（不含滚动）有几个在发光的东西？超过两个就砍。
3. 关掉所有动画，页面还好看吗？不好看说明氛围是拿动效垫的。
4. 正文的对比度到 4.5:1 了吗？青绿和品红在暗底上的实际对比度往往低于预期。
5. 把最亮的那一点移到别的位置，视线还知道往哪看吗？不知道就说明你只有一堆亮点，没有焦点。

这五条过完通常能删掉三分之一装饰。删掉的那部分，才是这套美学真正的成本。
